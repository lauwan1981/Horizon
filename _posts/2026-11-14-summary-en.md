### [Claude Code Stop hook exit code 2 retry](https://aihot.news/items/p0jsxs2bnv6tmnmn1soi56759) ⭐️ 5.0/10

In Claude Code, a Stop hook that exits with code 2 returns its stderr to the CLI, prompting an automatic retry of the preceding check, whereas exiting with code 1 causes Claude to terminate without retrying. Lydia Hallie shared this technique as a way for users to configure automated checks to re-run on failure rather than end immediately. The method requires no additional tooling beyond adjusting the hook&\#x27;s exit behavior.

rss · AIHot-Token羊毛 · Nov 13, 18:43

**「Background」** Claude Code allows users to define Stop hooks that run after automated checks. The hook&\#x27;s exit code then determines whether the CLI retries or terminates.

**「Impact」** Claude Code users can configure Stop hooks to exit with code 2, enabling automatic retry of failed checks instead of immediate termination. This directly affects automated workflow reliability.
